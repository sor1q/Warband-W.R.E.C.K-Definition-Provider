# Warband-W.R.E.C.K-Definition-Provider
A lightweight VS Code extension designed for Mount &amp; Blade Warband Module System and WRECK developers.

It provides seamless Go to Definition support (Ctrl + Click or F12) for custom scripts, items, troops, and other game entities (e.g., script.try_use_rootpath, itm.sylvan_bow). The extension instantly scans your project files and jumps directly to the entity declaration line in module_*.py
